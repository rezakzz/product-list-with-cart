# Dessert Cart App

Interactive dessert ordering application built with HTML, CSS, and JavaScript.

## Live Demo
🌐 https://dessert-cart-app.vercel.app

## Features
- Add items to cart
- Increase/decrease quantity
- Remove items from cart
- Dynamic order total calculation
- Order confirmation modal
- Responsive layout for desktop, tablet, and mobile
- Responsive product images using `<picture>`
- Hover and active interactive states

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- CSS Grid
- Flexbox
- Responsive Design
- Vercel
